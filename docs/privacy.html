개인정보처리방침

시행일: 2026년 9월 20일

1. 수집하는 개인정보

이 서비스는 이용자로부터 개인정보를 수집하지 않습니다.

이 서비스에는 회원가입 · 로그인 · 문의 양식 · 쿠키 · 분석 도구가 없습니다.

2. 페이지 접속 기록

이 페이지는 GitHub Pages로 제공되며, GitHub가 접속 기록을 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 처리방침을 확인하십시오.

3. YouTube API 서비스로 받는 데이터

이 서비스는 YouTube API 서비스를 사용합니다. 받는 데이터는 다음뿐입니다.

  • 공개 인기 동영상의 공개 메타데이터 (videos.list, chart=mostPopular, regionCode=KR)
  • 프로젝트 채널에 올릴 영상의 공개 통계 (videos.list, part=statistics)

OAuth로 접근하는 계정은 프로젝트 채널 하나뿐입니다. 다른 이용자의 비공개 데이터에 접근하지 않습니다.

받은 데이터를 제3자에게 제공하거나 판매하지 않습니다.

4. 이용 목적과 보관

받은 데이터는 프로젝트 분석 목적으로만 씁니다. 보관과 갱신은 YouTube API 서비스 개발자 정책이 정한 기준을 따릅니다.

5. 관련 약관과 권한 철회

  • YouTube 서비스 약관
  • Google 개인정보처리방침
  • Google 계정에 부여한 접근 권한은 Google 계정 권한 관리 페이지에서 철회할 수 있습니다.
